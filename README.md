# GridDemo

GridDemo is a simple WPF (Windows Presentation Foundation) application demonstrating the use of a **Grid layout**, basic controls like `TextBox`, `Button`, and `Menu`, and event handling in C#.

---

## Features

- Responsive **Grid layout** with rows and columns
- User input for **First Name** and **Last Name**
- **Submit button** displays a greeting using a `MessageBox`
- Simple **Menu** with `File` and `Edit` options
- Basic styling with fonts, colors, and background rectangles
